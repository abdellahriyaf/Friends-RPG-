FRIENDS RPG - REMAINING MOD ASSETS
Minecraft 1.20.1 / Fabric

Contents:
- assets/mod-items/<namespace>/*.png : generated 128x128 item sprites built from original item-model texture layers.
- assets/entity-textures/<namespace>/*.png : original entity textures copied unchanged.
- mod-image-map.json : matches existing Artifact ranking entries to exact extracted item icons where a name match exists.
- manifest.json : source model, texture layer, item name and extraction audit.
- README.txt

Important:
These are source-derived images, not hand-drawn approximations. Item sprites are 2D composites from item model texture layers. Custom 3D models and block-model renders are not falsely represented as flat item sprites. Entity PNGs are raw textures, not rendered mob previews.

The archive contains assets from:
Artifacts, BetterEnd, World Bosses, Traveler's Backpack, Waystones,
Bosses of Mass Destruction, Runes, Remnant Mobs and Alloy Forgery.
Other included libraries/frameworks did not contain useful player-facing item sprites.
